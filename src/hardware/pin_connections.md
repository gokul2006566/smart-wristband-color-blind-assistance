# Hardware Pin Connections

## ESP32 to TCS3200 Color Sensor

| TCS3200 Pin | ESP32 Pin |
|-------------|-----------|
| S0 | GPIO 5 |
| S1 | GPIO 18 |
| S2 | GPIO 19 |
| S3 | GPIO 23 |
| OUT | GPIO 4 |
| GND | GND |
| VCC | 3.3V* |

## Notes

- The TCS3200 sensor is used to detect the RGB components of an object.
- The ESP32 reads the frequency generated by the TCS3200.
- S0 and S1 control the output frequency scaling.
- S2 and S3 select the color filter.
- GPIO 4 receives the sensor output signal.

*Use a supply voltage compatible with your specific TCS3200 module. 
ESP32 GPIOs are 3.3V logic and are not 5V tolerant.
